## Описание

Random Quote Generator — это десктопное GUI‑приложение на Python, которое:
* генерирует случайные цитаты из предопределённого списка;
* отображает историю сгенерированных цитат;
* позволяет фильтровать цитаты по автору и теме;
* сохраняет историю и список цитат в JSON‑файл между запусками;
* проверяет корректность ввода данных.

## Функциональность

* **Кнопка «Сгенерировать цитату»** — выбирает случайную цитату из списка (с учётом фильтров).
* **История цитат** — отображает все сгенерированные цитаты в виде прокручиваемого списка с нумерацией.
* **Фильтры**:
  * по автору (выпадающий список);
  * по теме (выпадающий список).
* **Кнопки управления**:
  * «Очистить историю» — очищает историю без удаления цитат;
  * «Сохранить историю» — сохраняет текущую историю и цитаты в файл `quotes_data.json`.
* **Автозагрузка данных** — при запуске приложение загружает сохранённые цитаты и историю из `quotes_data.json`, если файл существует.
